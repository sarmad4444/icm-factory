# Pipeline Mapping Patterns (Layer 3)

- **3-Stage Pattern (Transformational)**: Ingest -> Process -> Format
- **4-Stage Pattern (Analytical)**: Ingest -> Extract -> Synthesize -> Report
- **5-Stage Pattern (Creative / Production)**: Brief -> Architecture/Script -> Drafting -> Styling -> Assembly
- **Rule of Thumb**: Aim for 2 to 5 stages. Workflows exceeding 6 stages should often be split into separate workspaces.
