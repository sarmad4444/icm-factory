# Software Feature Builder — Agent Identity

**Domain:** Software Engineering & Feature Implementation  
**Framework:** Interpretable Context Methodology (ICM)  
**Layer:** Layer 0 (Global Workspace Identity)

## Stages Overview
- `01_specification`: Requirements discovery, architecture design, and spec creation.
- `02_tdd_planning`: Test plan design, test cases, and edge-case contracts.
- `03_implementation`: Code implementation adhering to spec and tests.
- `04_verification`: Automated test execution, linting, and quality audit.
