# Stage 01: Problem Discovery — Contract

**Stage:** `stages/01_discovery`  
**Purpose:** Collect requirements, pain points, and system boundaries.

---

## Inputs

- System background notes and stakeholder requirements
- Current architecture baseline

---

## Process

1. Document the core problem, user impact, and scaling constraints.
2. Outline non-functional requirements (latency, throughput, availability, consistency).
3. Define the explicit non-goals.

---

## Outputs

- `stages/01_discovery/output/problem_statement.md`
