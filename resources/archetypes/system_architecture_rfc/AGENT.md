# System Architecture RFC — Architecture Design & RFC Engine

**Mission:** Evaluate technical options, analyze tradeoffs, diagram systems, and generate consensus-ready RFCs.  
**Framework:** Interpretable Context Methodology (ICM)  
**Status:** Active

---

## 1. Operating Rules

1. Follow the 5-stage architectural design sequence strictly.
2. Ground all decisions in concrete tradeoffs and system requirements.
3. Keep diagrams and migration plans versioned alongside the RFC text.

---

## 2. Stages Overview

- `stages/01_discovery`: Problem Discovery & Requirements Gathering
- `stages/02_tradeoffs`: Architecture Alternatives & Tradeoff Matrix
- `stages/03_diagrams`: System Component & Sequence Diagrams
- `stages/04_migration`: Rollout, Data Migration & Risk Assessment
- `stages/05_rfc`: Final RFC Document Generation & Review
