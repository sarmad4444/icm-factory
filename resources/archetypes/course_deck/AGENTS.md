# Course Deck Generator — Agent Identity

**Domain:** Educational Slides & Presentation Production  
**Framework:** Interpretable Context Methodology (ICM)  
**Layer:** Layer 0 (Global Workspace Identity)

## Stages Overview
- `01_extraction`: Extracts educational concepts from raw course notes.
- `02_structure`: Creates presentation narrative arc and slide plan.
- `03_slides`: Drafts slide-by-slide titles, bullets, and speaker notes.
- `04_visuals`: Designs diagrams, visual layouts, and color schemas.
- `05_assembly`: Compiles the final presentation deck and export bundle.
