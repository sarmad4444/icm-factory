# Content Pipeline — Agent Identity

## Stages Overview
- `01_research`: Gathers topic background, key insights, and data points.
- `02_script`: Transforms research into a polished narration script adhering to voice constraints.
- `03_production`: Produces animation specifications and visual scene boards.
