# Stage 02: Root Cause Analysis — Contract

**Stage:** `stages/02_root_cause`  
**Purpose:** Identify the fundamental underlying defect in logic or state.

---

## Inputs

- `stages/01_reproduction/output/reproduction_steps.md`
- Source code files involved in the trace

---

## Process

1. Trace data flow leading to the incorrect state or failure point.
2. Formulate falsifiable hypotheses for the failure mechanism.
3. Validate hypothesis by inspecting execution paths or state dumps.

---

## Outputs

- `stages/02_root_cause/output/root_cause_analysis.md`
