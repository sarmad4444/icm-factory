# Stage 01: Bug Reproduction — Contract

**Stage:** `stages/01_reproduction`  
**Purpose:** Reproduce the reported defect in a deterministic test or script.

---

## Inputs

- Bug report, stack traces, and user logs
- Current codebase state

---

## Process

1. Isolate the minimal inputs required to trigger the bug.
2. Record observed error output vs expected correct output.
3. Build a reproducible script or reproduction environment.

- `stages/01_reproduction/output/reproduction_steps.md`
